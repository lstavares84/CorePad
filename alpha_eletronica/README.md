# Alpha | desenvolvimento eletrônico

Referência visual aprovada: Alpha Blender 1.2.0. Primeira revisão eletrônica: 0.1.0, em 22/11/2026.

A eletrônica pode exigir alterações de dimensões, espessura e montagem interna. Preservar o conceito e os controles; atualizar o Blender somente depois de resolver o empilhamento real.

Abra `v0.1.0/Alpha_Eletronica_v0.1.0.md` para consultar as decisões, componentes e pendências. Os dois arquivos KiCad são estudos editáveis de posicionamento. Não contêm esquema elétrico, redes ou trilhas e não estão liberados para fabricação. As reservas sem terminais não são desenhos de soldagem.

O pedido de autonomia foi incorporado: alimentação USB-C e bateria interna, com meta de pelo menos 30 horas de gravação ambiente, referenciada no Plaud Note original. A autonomia depende de medição em protótipo.

Versões eletrônicas seguem MAJOR.MINOR.PATCH separadamente do Blender. Não sobrescrever revisões entregues. A revisão 0.1.0 contém proposta de arquitetura, BOM preliminar, orçamento energético, interligações funcionais, estudo de posicionamento e plano de validação. Não contém firmware nem placa funcional.
